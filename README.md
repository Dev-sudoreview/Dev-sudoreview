# Sudo Review

**Honest software reviews from developers who actually use it.**

[Sudo Review](https://sudoreview.dev/) is an independent review site for developer tools. We don't score a tool from a landing page or a demo. Every tool is used for at least four weeks in a real project before it gets a rating. We take no sponsorships and no paid placements, so a score reflects what it was like to build with the tool.

## How we score

Each review is scored out of 10 on three weighted criteria:

| Criterion | Weight |
|---|---|
| Developer experience | 40% |
| Speed | 30% |
| Value | 30% |

## What we cover
